## 简体中文

GO27Q32 Lite 的首个公开版本，为技嘉 GO27Q32 提供画面调节、Windows HDR、应用自动配置、配置库、游戏辅助和托盘快捷操作。

- **推荐下载**：`GO27Q32Lite-1.0.0-windows-x64-setup.exe`。安装时可选择简体中文或 English，按当前用户安装，无需管理员权限。
- 便携版：`GO27Q32Lite-1.0.0-windows-x64.zip`。完整解压后运行，保留全部 DLL 和子目录。
- 已包含 .NET 与 Visual C++ 运行库。支持 Windows 10/11 x64。
- “设置 → 检查更新”仅在 GitHub 正式版高于本地版本时提示，不自动下载或安装。
- 配置目录统一为 `%LOCALAPPDATA%\GO27Q32Lite`。首次升级时，若新目录没有配置，会从旧目录复制；升级和卸载保留配置。

HDR 专用预设仍需在机身菜单选择。当前不提供 macOS 版本或 KVM 功能。程序未签名，Windows 可能显示未知发布者。

下载校验值见 `SHA256SUMS.txt`。源代码采用 MIT License，字体和运行库按各自许可分发。

## English

The first public release of GO27Q32 Lite: picture controls, Windows HDR, per-application profiles, Game Assist, and tray controls for the GIGABYTE GO27Q32.

Download the **Windows x64 setup executable** for a per-user installation with a Simplified Chinese / English language selector. The portable ZIP is also available. Both include the .NET and Visual C++ runtimes.

Update checks are manual. Only a newer stable GitHub release triggers an update notice; nothing is downloaded or installed automatically. Existing settings are preserved during upgrades and uninstallation.

HDR-specific presets must be selected on the monitor's OSD. No macOS or KVM support is included. Binaries are unsigned. Checksums are listed in `SHA256SUMS.txt`.
