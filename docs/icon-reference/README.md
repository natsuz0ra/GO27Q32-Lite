# 图标来源与生成记录

参考页面：https://www.gigabyte.com/Monitor/GO27Q32

官方外观图：https://www.gigabyte.com/FileUpload/Global/KeyFeature/4405/innergigabyte/images/scenario.jpg

通过浏览器读取并保存官方图片作为造型参考。可辨识特征：窄边框宽屏、中央立柱、扁平矩形底座。未使用原图中的文字或场景作为应用图标。

使用内置 image_gen 工具，透明背景；最终文件 assets/icons/go27q32.png。tool/export-icons.ps1 仅执行等比缩放和 PNG/ICO 格式打包，保留 alpha；不需要运行时图像生成服务。

最终提示词：

> Edit image 1 into a STRICTLY FLAT minimalist application icon. Image 2 is reference for the real Gigabyte GO27Q32 silhouette only. Keep the recognizable front-facing widescreen panel, central upright support, and a plain flat RECTANGULAR base. Redraw everything as flat solid-color 2D geometric shapes, crisp vector-style edges. Absolutely NO photorealism, NO 3D, NO bevel, NO metal, NO textures, NO shading, NO drop shadows, NO gradients, NO glow. A solid charcoal thick rounded-rectangle screen rim, a flat medium gray short rectangular stand and rectangular base. Inside the screen use only 3 solid color polygons: deep cobalt blue field, one broad lighter blue diagonal band and one broad cyan diagonal band, with straight clean boundaries. Extremely simple, about 7 shapes in the entire icon, designed for excellent readability at 16px Windows tray size and 48px sidebar size. No words, no numbers, no logo, no enclosing app tile, no purple background. Single centered icon on a truly transparent background. Square canvas; the monitor occupies 92 percent of canvas width. Retain the 16:9 screen proportions, use a short stand to keep the icon substantial. Output only the clean flat icon, not a presentation sheet.
