# 1.0.2 验证记录

日期：2026-11-06。

公共下拉框原先把整个 InputDecorator 放进圆角裁剪层。浮动标签会绘制到控件布局上方，因此标签上半部分被裁掉。本次取消外层裁剪，给 InkWell 单独指定圆角，保留悬停效果的边界。

HDR 控件原先在应用规则开启时禁用。本机只读检查确认 Windows HDR 请求和实际输出均正常，配置开启了自动切换。本次允许直接手动切换；后端在请求有效、输出状态稳定后，先暂停规则，再发送 HDR 操作。暂停保留当前画面，不恢复旧基线，也不修改已保存配置。无效的预设请求不会暂停规则。

| Flutter 测试 | 40 项通过；增加浮动标签上半部分像素检查、圆角悬停边界检查和规则开启时的 HDR 开关操作 |
| 核心检查 | 58 项通过 |

自动化交互检查使用模拟设备，没有切换真实显示器的 HDR 或预设。实机界面由用户手动启动后验收。
