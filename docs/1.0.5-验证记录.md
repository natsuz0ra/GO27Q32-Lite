安装器继续使用 Inno Setup 原生语言选择框。`LanguageDetectionMethod=none` 配合首项 English，使默认选择固定为英文；`UsePreviousLanguage=no` 避免上次安装语言改变默认选项。用户仍可选择简体中文，或通过 `/LANG=zhCN` 指定中文安装。

安装完成时，安装器将 `en` 或 `zh` 写入 `%LOCALAPPDATA%\GO27Q32Lite\settings.json.install-language`。软件下次读取偏好时，先加载或迁移已有配置，再只更新语言字段。成功保存后删除这份临时选择。因此不勾选安装后的“打开”也会生效；用户之后在软件内修改的语言不会被重复覆盖。升级安装会重新应用本次安装选择。
