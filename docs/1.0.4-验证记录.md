# 1.0.4 验证记录

日期：2026-11-06。

旧版编辑器按 Windows 当前输出模式，将读数放入 `Values` 或 `HdrValues`。实机协议验证已经说明，HDR 下的常规 GetVCP 读数不能当作 HDR 参数。本版停止这种分类和套用方式。

- `Values` 保存 SDR 参数。只有当前实际输出为 SDR，新建配置才会采集常规读数。
- `HdrPreset` 保存 HDR 预设请求，空值保持当前，0～4 为五档预设；不从读数或“上次请求”推断当前档位。
- `HdrValues` 保留用于兼容和导出，运行时永不套用。编辑器可手动复制旧参数到 SDR，仅补充未选择的字段，已有值保持不变；不复制不可靠的旧画面模式字段。
- HDR 下的亮度、对比度、锐度、Gamma、色温等常规控制在前后端同时禁用。HDR 读取和轮询不再把对应值暴露为当前参数。准星、音量和设备设置保留。
- 自动规则不采集、应用或恢复 HDR 常规参数基线。HDR 预设切换沿用手动操作的黑屏恢复流程；未确认时暂停规则，不立即重发或进行预设回滚。
- 若从 HDR 启动且规则会切换预设，桌面默认配置必须明确返回某一预设或关闭 HDR。无法读取初始预设，因此不声称能够自动恢复未知档位。
