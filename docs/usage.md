# 使用说明

## 连接显示器

让 GO27Q32 保持唤醒，在 Windows“设置 → 系统 → 屏幕”中启用它。未启用的显示路径无法提供稳定的 DDC 控制通道。软件离线时保留配置库和规则，可在“设置”中重新检测。

输入源切换会中断当前画面，软件会先要求确认。对应值为 HDMI 1、HDMI 2、DisplayPort 和 USB-C。显示路径恢复后，软件重新绑定原设备。

## 调节与配置

滑杆结束拖动后写入，再读取确认；失败时回到已确认值。临时调整可撤销，不会自动覆盖命名配置。“存为配置”可以保存当前画面。

Gamma 顺序是关闭、1.8、2.0、2.2、2.4、2.6。准星提供关闭及 1～4 档。sRGB、ECO 或 HDR 可能锁定部分参数，软件会显示禁用原因。

每个配置分别保存 SDR/HDR 参数，HDR 策略可选保持、开启或关闭。切换系统 HDR 后，只应用目标模式下保存的那组参数。HDR 专用画面预设仍通过机身菜单选择。

## 应用自动切换

新建规则时选择完整 EXE 路径，可从运行中的应用选择。连续两轮检测到相同目标后套用配置，检测间隔约 1.5 秒。多个应用同时命中时，优先级数字较大的先执行，同级按列表顺序。

所有匹配应用退出后，回到桌面默认配置；未指定时，恢复自动化启用前的画面。暂停自动化会保留当前画面。自动化运行时，画面手动调整暂时禁用，OSD 等设备偏好仍可单独修改。

规则页会报告查询路径失败或显示路径暂不可用。受保护进程可能拒绝查询，此时保留当前配置并重试。

## 外部状态同步

启用同步后，Windows HDR 和亮度通常每 1.5 秒读取一次。其余 DDC 参数分组轮询，完整一轮通常约 10.5 秒。设备读取耗时、正在写入和切换 HDR 会延长周期。

同步只合并实际读到的值。拖动滑杆时会延后刷新，避免旧读数覆盖正在调整的值。

## 游戏计时器与设备偏好

计时器支持正计时、倒计时、暂停/继续和独立关闭按钮，时间范围为 00:00～99:59。倒计时设为 00:00 时，按设备规则从 05:00 开始。启动会重置计时。

OSD 时间、透明度、指示灯、摇杆快捷功能和计时器属于设备偏好，不随应用画面配置或画面撤销而回退。

## 托盘与启动

单击图标打开亮度、快捷配置、准星和 HDR 等快捷控件；双击打开主窗口。主窗口可见时，浮层不会隐藏主窗口。右键图标可以退出程序。

开机自启仅修改当前用户的启动项。安装程序不会擅自启用它。卸载时，只清理指向当前安装目录的启动项，并保留用户配置。

命令行参数：

```powershell
.\go27q32_lite.exe --show   # 忽略本次启动的最小化偏好
.\go27q32_lite.exe --tray   # 在托盘启动
.\go27q32_lite.exe --demo   # 纯演示，不访问硬件或保存设置
```

## 更新与迁移

在“设置”里手动检查更新。发现更高版本后打开下载页，下载新的安装程序。升级前从托盘退出程序，再安装到原目录；用户配置会保留。

导入 JSON 会整体替换本版本的配置和规则。导入前会验证内容，保存后不会立即改写硬件。迁移前先导出一份备份。
